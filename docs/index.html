Install

  1. Get the build from GitHub Releases
  2. Unblock the archive in Properties if Windows marked it
  3. Extract and launch the matching .bat as a normal user (admin is not required)
  4. Confirm http://127.0.0.1:8188
  5. Add models, then save a working workflow as JSON

How to tell it worked

ComfyUI is up when the local URL opens. A black output usually means no checkpoint loaded — add one, then Queue Prompt again.

FAQ

Do I need Python?

No. comfyui-portable-2026 is a portable Windows pack. Extract and run the .bat for your GPU.

Where do models go?

Put .safetensors checkpoints in models/checkpoints. LoRAs and VAEs have their own folders. Missing files show as red nodes.

NVIDIA or AMD?

NVIDIA: run_nvidia_gpu.bat (6 GB+ VRAM recommended). AMD: DirectML/ROCm launcher. CPU works but is slow.

Is this the official ComfyUI?

The engine is the open-source project https://github.com/Comfy-Org/ComfyUI. This page is the Windows pack named comfyui-portable-2026.
